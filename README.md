# Таблица с Ёжиком

Тренажёр таблицы умножения для телефона: очки, звания, достижения, дневная норма и отчёт для родителя.

**Открыть:** https://vini-dav.github.io/ezhik-multiplication/

## Как поставить на телефон

- **Android (Chrome):** открыть ссылку → меню ⋮ → «Добавить на главный экран» / «Установить приложение».
- **iPhone (Safari):** открыть ссылку → «Поделиться» → «На экран „Домой“».

После первого открытия работает и без интернета.

## Дневная норма

За день нужно правильно решить заданный процент **разных** примеров таблицы (по умолчанию 85% — 55 из 64 для таблицы 2–9). Каждый новый пример даёт 10 зачётных очков. Порог, диапазон таблицы и PIN-код для настроек меняются в разделе для родителя (иконка с ползунками).

Прогресс хранится в браузере телефона — не очищайте данные сайта.

## Одень ёжика к Новому году

На главной есть новогодний гардероб: колпак Деда Мороза, шарф, праздничная шубка и валенки. Все четыре вещи можно носить одновременно, а купленные вещи — свободно снимать и надевать. Наряд виден и во время занятий.

За выполнение дневной нормы начисляется **20 снежинок один раз в день**. Каждая вещь стоит **100 снежинок**: одна покупка за 5 учебных дней, весь комплект — за 20. Пропуски не сжигают накопления. Снежинки не расходуют очки опыта и не влияют на звания. Начисление начинается с первой выполненной нормы после обновления; прошлые дни не пересчитываются.

Покупки и выбранный наряд сохраняются вместе с прогрессом под прежним ключом `umnozh.v1`. При обычном обновлении приложения они сохраняются; полный сброс прогресса в настройках удаляет и гардероб.

## Проверки

### Резервная копия

Настройки родителя → «Резервная копия / перенос» → «Скачать копию». Импорт проверяет файл и запрашивает подтверждение перед заменой данных. В файле есть имя, PIN, история и гардероб: не публикуйте его. Перед импортом дополнительно сохраняется один локальный снимок под ключом `umnozh.v1.before-import` (это не замена скачанному файлу).

### Тестовый сайт

GitHub Pages разных репозиториев одного аккаунта использует общий origin и `localStorage`. Нельзя просто копировать рабочий сайт в другой репозиторий с тем же ключом! Соберите изолированную версию:

```sh
node scripts/build-preview.cjs /tmp/opencode/ezhik-preview
```

Публикуйте только содержимое этой папки в тестовом репозитории. Сборка использует ключ `ezhik.preview.v1` и кэши `ezhikPreview-*`, не удаляет рабочие кэши `ezhik-*`. Кнопка скачивания основного прогресса только читает `umnozh.v1`; если браузер/PWA хранит данные отдельно, копия может быть недоступна — не очищайте данные и не переустанавливайте приложение.

Для проверки обновления: сначала опубликуйте старую версию с такой же изоляцией и заработайте тестовый прогресс, затем обновите **по тому же тестовому адресу**. Сравните очки, достижения и норму. Только после проверки сливайте PR в основной `main`.

### Автотесты

Без установки зависимостей, с Node.js 18+:

```sh
node --test tests/*.test.cjs
```

Интеграционный тест в Chromium проверяет реальное обновление старой версии на новую по одному адресу, покупки, скачивание/импорт копии и неизменность основного хранилища. Нужны Playwright и Chromium:

```sh
npm install --prefix /tmp/opencode/ezhik-browser playwright
/tmp/opencode/ezhik-browser/node_modules/.bin/playwright install chromium
NODE_PATH=/tmp/opencode/ezhik-browser/node_modules node tests/browser-upgrade.cjs
```

Для системного Chromium укажите `CHROMIUM_PATH=/usr/bin/chromium`. Тест использует только временный локальный сайт и искусственные данные; рабочий сайт не открывает.
