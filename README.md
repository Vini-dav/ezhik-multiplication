# Таблица с Ёжиком

Тренажёр таблицы умножения для телефона: очки, звания, достижения, дневная норма и отчёт для родителя.

**Открыть:** https://vini-dav.github.io/ezhik-multiplication/

## Как поставить на телефон

- **Android (Chrome):** открыть ссылку → меню ⋮ → «Добавить на главный экран» / «Установить приложение».
- **iPhone (Safari):** открыть ссылку → «Поделиться» → «На экран „Домой“».

После первого открытия работает и без интернета.

## Дневная норма

За день нужно правильно решить заданный процент **разных** примеров таблицы (по умолчанию 85% — 55 из 64 для таблицы 2–9). Каждый новый пример даёт 10 зачётных очков. Порог, диапазон таблицы и PIN-код для настроек меняются в разделе для родителя (иконка с ползунками).

Прогресс хранится в браузере телефона — не очищайте данные сайта.

## Файлы

- `index.html` — всё приложение в одном файле
- `manifest.webmanifest`, иконки — установка на главный экран
- `sw.js` — офлайн-режим
